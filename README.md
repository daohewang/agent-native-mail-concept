# Relay · Agent 时代的邮箱

一份面向 Tenth Global 产品设计笔试的可交互前端概念作品。核心观点：邮箱首页应优先呈现**正在推进的结果**，同时让 Agent 的依据、步骤和权限保持可见；最终发信仍由用户确认。

## 体验路线

1. 打开工作台，点开「确认北岸工作室的合作范围」。查看 Agent 的步骤、两封引用邮件与回复草稿；可编辑、退回修改，或审阅后确认模拟发送。
2. 在顶部写一句新目标，或点一个示例。Relay 会模拟整理过程并停在人工确认处。
3. 进入收件箱，点一封邮件，选择「自己回复」或「交给 Agent」。
4. 在「权限与边界」查看哪些动作可自动准备，哪些必须人工批准。

所有邮件与人名都是虚构数据。作品没有邮箱连接、服务端请求或真实发信功能；刷新页面会重置演示状态。
新目标仅按演示邮件中的关键词匹配。没有相关邮件时，页面会如实提示，不会编造依据或回复。

## 本地运行

在本目录执行 `python3 -m http.server 4173`，然后打开 `http://localhost:4173`。JavaScript 使用原生 ES Module，不需要安装依赖。

运行状态模型检查：`node --test tests/state.test.mjs`。
